# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 7.1.x   | :white_check_mark: |
| 7.0.x   | :white_check_mark: |
| < 7.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it by opening an issue with the label `security`.
We will respond within 48 hours and work to fix it promptly.

**Do not** report security vulnerabilities through public GitHub issues if they could be exploited.
Instead, please email the maintainers directly.
