## 一、实现方案 + 框架选型

### 1.1 整体架构策略

v6.0 延续**四层模块化架构**，每一层可独立使用或替换：

```
题型分类层 (P0)  →  质量诊断层 (P0)  →  智能组卷层 (P1)  →  错题库层 (P2)
      │                   │                     │                   │
      ▼                   ▼                     ▼                   ▼
  题型库(PG) ←── Repository 抽象层 ←── IRT 引擎(已有) ←── 知识图谱(已有)
                                                │
                                          Redis L2 缓存
```

### 1.2 对各需求的技术方案（RQ-01 ~ RQ-22）

| 需求 | 技术方案 | 关键决策 |

| RQ-04 可视化 | ECharts 雷达图 + 直方图 | 复用已有 ECharts 组件模式 |

### 1.3 开放问题决策（Q1-Q10）

| 问题 | 决策 | 理由 |
|------|------|------|
| Q1 题型分类路线 | P0: 规则引擎+LightGBM；P2: LLM 增强 | LLM 增加依赖和成本，规则+LightGBM 可在无 GPU 环境下运行 |
| Q2 约束求解器 | OR-Tools CP-SAT (P1)，后续自研优化 | OR-Tools 成熟稳定，对 ≤50 题约束求解 <1s |
| Q3 IRT 实时性 | 预计算 + 增量更新缓存 | IRT 参数定期批量更新（如每日），组卷时 <100ms 读取 |
| Q4 错题隐私 | 引入 tenant_id + 行级隔离 | models.py 已有 tenant_id 字段，PG RLS 即可 |
| Q5 PG 迁移 | CLI 脚本 + 增量模式 + 回滚 | 见 RQ-21 方案 |
| Q6 导出格式 | P1: PDF(html2pdf)；P2: Word+LaTeX | html2pdf 最成熟，Word 需 python-docx |
| Q7 采集适配器 | 保留但默认关闭 | 已在 auto_scraper 中 enabled=False |
| Q8 移动端 | PWA 增强(v6.0)；原生App(v7.0) | 减少工作量 |
| Q9 AI 组卷 | P2，延至 v6.1 | 不占用核心功能资源 |
| Q10 商业模式 | MIT 社区版 + 企业增值服务 | 不涉及本次技术决策 |

### 1.4 模块划分

**模块 1：题型分类引擎** (`engines/question_classifier.py`)
- 输入：题目文本/选项/答案/知识点标签
- 处理：特征提取 → 规则匹配 → LightGBM 分类
- 输出：`{ main_type, sub_type, confidence }`

**模块 2：质量诊断模块** (`engines/hybrid_quality.py` + `services/quality_service.py`)
- CTT 指标：通过率(p)、区分度(D)、点双列相关
- IRT 指标：a(区分度)、b(难度)、c(猜测参数)、CFI/TLI/RMSEA
- 6 维报告：难度/区分度/信度/效度/知识点覆盖/题型分布
- 缓存策略：IRT 参数预计算 → Redis L2

**模块 3：智能组卷引擎** (`engines/composition_engine.py`)
- 约束建模：OR-Tools CP-SAT IntVar 数组
- 目标函数：最大化知识点覆盖率 + 最小化难度偏差 + 最大化区分度
- 真题优先策略：真题权重倍增

**模块 4：错题库模块** (`services/error_service.py` + `routes/errors.py`)
- 错题录入 → 分类 → 诊断（IRT θ + 知识图谱）→ 同类推荐

## 三、数据结构和接口（类图）

### 3.1 核心数据模型

```python
# QuestionType — 题型分类
class QuestionType:
    id: int
    subject_id: str          # 学科代码
    main_type: str           # "choice"|"fill"|"solve"|"composite"
    sub_type: str            # "single_choice"|"multi_choice"|"proof"|"calculation"
    name_cn: str             # 中文名称
    level: int               # 层级
    parent_id: int | None    # 父类型

# Question — 扩展（加 question_type_id FK + irt_params_cache）
class Question:
    id: int
    paper_id: int | None
    question_type_id: int | None   # 新增 FK
    q_number: int
    q_type: str                     # 旧字段，兼容迁移
    content: str
    options: str | None
    answer: str | None
    explanation: str | None
    score: float
    knowledge_points: str
    difficulty_tag: str | None
    irt_a: float | None
    irt_b: float | None
    irt_c: float | None
    discrimination: float | None
    irt_params_cache: str | None    # 新增 JSON: {a,b,c,cfi,tli,rmsea,ctt_p,ctt_d}
    source: str | None              # "real"|"platform"|"custom"
    year: int | None
    content_hash: str | None
    created_at: datetime
    tenant_id: str | None

# ErrorRecord — 错题记录
class ErrorRecord:
    id: int
    user_id: int
    question_id: int
    subject_id: str
    error_reason: str               # "concept"|"careless"|"calculation"|"strategy"|"other"
    user_score: float | None
    question_score: float
    attempt_count: int
    is_mastered: int                # 0|1
    mastered_at: datetime | None
    created_at: datetime
    tenant_id: str | None

# StudentProfile — 学生画像
class StudentProfile:
    id: int
    user_id: int
    subject_id: str
    theta: float                    # IRT 能力值
    theta_se: float                 # 标准误
    knowledge_mastery: str          # JSON: {kp_code: mastery_level}
    total_questions: int
    correct_questions: int
    last_updated: datetime
    tenant_id: str | None

# PaperTemplate — 组卷模板
class PaperTemplate:
    id: int
    name: str
    subject_id: str
    created_by: str
    constraints_json: str
    description: str | None
    is_public: int                  # 0|1
    created_at: datetime
    updated_at: datetime

# CompositionRecord — 组卷记录
class CompositionRecord:
    id: int
    name: str
    subject_id: str
    template_id: int | None
    created_by: str
    constraints_json: str
    question_ids_json: str          # 有序题号列表
    quality_report_json: str | None
    status: str                     # "draft"|"finalized"
    created_at: datetime
```

## 五、共享知识（跨文件约定）

### 5.1 数据层接口规范
```python
class BaseRepository:
    async def get(self, id: int) -> dict | None: ...
    async def list(self, filters: dict, page: int = 1, size: int = 20) -> dict: ...
    async def create(self, data: dict) -> int: ...
    async def update(self, id: int, data: dict) -> bool: ...
    async def delete(self, id: int) -> bool: ...
```

### 5.2 IRT 参数缓存策略
- 键格式: `f"irt:params:{question_id}"`
- 值格式: JSON `{"a": float, "b": float, "c": float, "cfi": float, "tli": float, "rmsea": float}`
- 缓存 TTL: 86400 (24h)，Redis L2
- 优先读缓存，未命中才调用 IRT 引擎

### 5.3 环境变量
```
GAOKAO_DB=sqlite|postgresql   # 数据库后端选择（dev 默认 sqlite）
DATABASE_URL=...               # PG 连接串
IRT_PREHEAT=true|false         # 启动时是否预热 IRT 缓存
```
