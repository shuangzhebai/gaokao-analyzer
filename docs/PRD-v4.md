# 高考模拟卷智能分析系统 v4.0 — PRD（产品需求文档）

## 一、产品目标

将 v3.0 升级为 v4.0，核心解决三大痛点：**数据质量差**、**搜索难用**、**界面丑且不稳定**。对标学科网/组卷网的内容丰富度，UI 采用 Apple Design 风格（极简、留白、毛玻璃），内置 DeepSeek 查重确保数据准确性。

## 三、功能需求池

### P0 — 必须有

#### 3.1 全新搜索引擎
- **全文检索**：SQLite FTS5，支持标题、省份、学校、考试标签、题目内容的全文搜索
- **多维度筛选**：科目、年份、省份、试卷类型、考试标签、分析状态，可组合
- **搜索建议**：输入时自动补全热门关键词
- **搜索排序**：按相关度、时间、来源优先级排序
- **搜索速度**：< 200ms 响应

#### 3.2 数据质量保障
- **来源追溯**：每份试卷记录来源网站、采集时间、采集人、原始URL
- **来源可信度评级**：S（教育部考试院）> A（省级教育部门）> B（学科网/菁优网）> C（个人上传）
- **DeepSeek 查重**：录入/采集试卷时，调用 DeepSeek API 对题目内容进行相似度检测
  - 相似度 > 90%：标记为重复，自动跳过
  - 相似度 70-90%：标记为疑似重复，需人工确认
  - 相似度 < 70%：正常录入
- **数据纠错**：可疑数据标记、审核工作流

#### 3.3 稳定性
- **全局异常处理**：所有 API 统一错误返回格式
- **数据库事务安全**：写入操作使用事务，失败自动回滚
- **输入验证**：所有 API 参数严格校验，拒绝非法输入
- **连接池管理**：数据库连接正确释放，防止泄漏
- **请求限流**：防止接口被滥用

#### 3.4 试卷采集
- **多源采集**：保留现有数据源，增加更可靠的来源
- **采集去重**：采集前先查数据库和 FTS，避免重复
- **采集日志**：每次采集记录详细日志（来源、URL、状态、耗时）
- **增量采集**：只采集新增数据，不重复处理已有数据

### P1 — 应该有

#### 3.5 试卷详情页
- **题目展示**：按题号排列，显示题型、分值、知识点标签、难度标记
- **答案解析**：折叠/展开答案和解析
- **知识点图谱**：可视化展示知识点覆盖
- **IRT 分析**：区分度、难度参数可视化
- **质量评分**：整体质量评分 + 各题质量标签

#### 3.6 分析功能
- **课标契合度**：知识点覆盖率、能力层次分布、核心素养达标
- **质量评估**：区分度、难度适当性、优质题推荐
- **拟合分析**：模拟卷 vs 真题对比
- **成绩模拟**：蒙特卡洛模拟 + 分数线预测 + 等级赋分

### P2 — 可以有

#### 3.7 高级功能
- **智能组卷**：按知识点和难度自动选题组卷
- **试卷对比**：多份试卷横向对比
- **导出功能**：试卷 PDF 导出、分析报告导出
- **数据统计大盘**：试卷库统计、知识点热力图

## 四、UI 设计要求

### 4.1 Apple Design 风格
- **极简主义**：大量留白，信息层级清晰
- **毛玻璃效果**：导航栏和卡片使用 backdrop-filter: blur
- **圆角**：统一使用 16px 圆角（Apple 标准）
- **阴影**：柔和的多层阴影，不使用硬边阴影
- **动画**：流畅的 CSS 过渡动画（0.3s ease）
- **字体**：SF Pro 风格，使用系统字体栈 -apple-system, BlinkMacSystemFont
- **配色**：白底为主，蓝色强调（#007AFF Apple Blue），辅以灰色层级
- **图标**：SF Symbols 风格，使用线性图标

### 4.2 页面结构
1. **顶部导航栏**：毛玻璃效果，固定定位
   - Logo + 系统名称
   - 全局搜索框（居中突出）
   - 快捷操作按钮
2. **侧边栏**：科目导航 + 快捷筛选
3. **主内容区**：
   - 仪表盘：统计卡片 + 最近试卷 + 快捷入口
   - 试卷库：搜索 + 筛选 + 列表/卡片切换
   - 试卷详情：题目列表 + 分析图表
   - 数据采集：采集面板 + 日志

### 4.3 交互细节
- 搜索框：输入即搜索（debounce 300ms），下拉建议
- 卡片：悬停时轻微上浮 + 阴影加深
- 筛选器：胶囊式多选，选中状态高亮
- 表格：斑马纹，操作按钮悬停显示
- Toast 通知：右上角弹出，自动消失

## 五、技术约束

| 项目 | 约束 |
|------|------|
| 后端 | FastAPI + aiosqlite（保持轻量，个人使用） |
| 前端 | 单页 HTML + Tailwind CSS + Chart.js（不引入构建工具） |
| 数据库 | SQLite + FTS5（全文搜索） |
| AI 查重 | DeepSeek API（按需调用，有频率限制） |
| 部署 | 本地运行，单进程 |
| 数据规模 | 1000+ 份试卷，5 万+ 道题目 |

## 六、与 v3.0 的核心差异

| 维度 | v3.0 | v4.0 |
|------|------|------|
| 搜索 | LIKE 模糊匹配 | FTS5 全文检索 + 排名 |
| 数据质量 | 无验证 | DeepSeek 查重 + 来源评级 |
| UI | 暗色商务风 | Apple Design 极简白 |
| 稳定性 | 频繁 500 错误 | 全局异常处理 + 事务安全 |
| 数据库 | 基础索引 | FTS5 + 完善索引 + 级联删除 |
| 筛选 | 仅科目 | 多维度组合筛选 |
| 来源追踪 | source_url 单字段 | 完整来源链（网站+URL+时间+可信度） |
